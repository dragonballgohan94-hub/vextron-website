CORE TECHNOLOGY

Intelligent monitoring features of the VEXTRON prototype.

01 / OBJECT DETECTION

Dual ultrasonic sensors monitor two detection points and identify object movement.

02 / SPEED ESTIMATION

Movement speed can be estimated using sensor spacing and the time difference between detections.

03 / SAFETY ALERTS

ESP32-based warning logic reports proximity and alarm conditions to the dashboard.

04 / LIVE MONITORING

Monitor sensor distances, controller state and system events through a web interface.

05 / EVENT TRACKING

View changes in object count, direction, speed and alarm state during operation.

06 / EMBEDDED CONTROL

ESP32 provides the connection between sensors, alarm hardware and the monitoring interface.
